# Brag Plan: ConstructIQ

## What is this app?
ConstructIQ is an enterprise real-time construction operations command and financial telemetry platform featuring 5 role-based views, interactive Gantt scheduling, INR budget variance analytics, and live site simulation.

## The angle
Mission control for multi-crore skyscraper operations. Rather than generic project management boards, ConstructIQ treats complex civil construction like an aerospace launchpad: live weather telemetry, sensor-driven crane shutdowns, role-switched command views, and multi-currency cost performance index tracking.

## Hook (first 2-3 seconds)
A dramatic architectural title lockup over an engineering grid: "ConstructIQ ENTERPRISE — Real-Time Operations Command", flanked by live site sensors ticking: "Wind: 8 mph • Temp: 78°F • CPI: 1.08".

## Key moments (the middle)
- **Multi-Role Perspective Shift:** Instant switching between Senior PM, Site Superintendent, and Financial Controller — reconfiguring timelines, crews, and ledger variance in real time.
- **Interactive Gantt & Financial Telemetry:** Tracking ₹42.8 Cr budget, phase completions (Excavation, Foundation, Framing L1-L5), and cost-performance index in INR.
- **Automated Site Hazard Telemetry:** High wind sensor alert (24 mph) instantly triggers automated tower crane shutdown protocols and feeds the AI Copilot.

## Outro / punchline
"Civil engineering moves fast. Now your telemetry moves faster." ConstructIQ logo lockup with gold accent and enterprise badge.

## User flow worth showing
1. Entry: Live site command console boots up with real-time KPI scorecards (₹42.8 Cr Active Budget, 78% Milestone On Track, 0 Lost-Time Days).
2. Key Action: Switching stakeholder role to Site Superintendent, viewing Gantt phase execution and scheduling dependencies.
3. Result: Real-time sensor alert flags wind hazard threshold, triggering automated safety shutdown and AI Copilot diagnosis.
